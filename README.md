# Royal Rex Hotels & Spa — Premium Website Concept

A modern multi-page hospitality experience for Royal Rex Hotels & Spa, Lagos.

## Stack
- Next.js 15 / React 19 / TypeScript
- Tailwind CSS
- Framer Motion-ready architecture
- Responsive, Vercel-ready

## Pages
Home, Rooms, individual room pages, Restaurant, Spa, Pool, Events, Lounge, Experiences, Gallery, About, Contact and Direct Booking.

## Run locally
```bash
npm install
npm run dev
```

> This is a concept upgrade. Published prices/contact details are based on the current Royal Rex website and should be reconfirmed before production launch. Some editorial imagery is temporary concept photography pending a complete approved Royal Rex media library.
